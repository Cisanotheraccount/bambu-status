# Changelog

## 0.4.0 — Community Preview (2026-10-05)

- Exported a clean, independent public source tree from the private 0.3.5 baseline.
- Added local discovery, explicit report-validated pairing, protected Access Code storage, and bilingual setup.
- Generated AMS options from real units and preserved bindings by stable unit ID.
- Replaced platform-specific image conversion with portable JPEG/PNG decoding; universal macOS helpers.
- Required fresh manual-check/reference frames; invalidated stale clear results and surfaced failures.
- Persisted first-observed ETA with task/date context; preserved +1D labels and existing display toggles.
- Added an experimental camera transport adapter; X1 requires external FFmpeg.
- Added clean runtime bundles, checksums, source/privacy audit, synthetic rendered graphics, and release documentation.
- Did not overwrite existing Studio pages, install over the private plugin, or claim universal physical validation.

## 0.3.5 — Private baseline

P1S monitor with layered tiles, AMS/fans/light, local reminders and 13-tile camera mosaic. Camera recovery added one waiting socket, graceful close, backoff, stale-event guards and watchdogs. The prior development record included 74 passing tests; this is historical evidence, not the public release's current test count.
